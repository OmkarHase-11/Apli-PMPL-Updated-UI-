# Apli-PMPL-Updated-UI-
A collaborative mobile app UI design project created using Figma.
## Project Overview

Apli-PMPL Updated UI is a mobile application UI concept designed for public transport users. The app aims to make transport-related information easier to access through a simple and attractive interface.

## Figma Design

View the complete Figma design here:

[Open Figma Design](https://violin-dude-19927349.figma.site/)

## Features

- Modern mobile app UI
- Dark mode supported interface
- Language selection screen
- Clean navigation flow
- Public transport app concept
- User-friendly layout
- Mobile-first design
